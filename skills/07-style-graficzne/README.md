# Style graficzne (art direction)

**Kiedy:** Dobierz 1–2 style jako kierunek wizualny assetu/sceny.

| Skill | Do czego |
|---|---|
| `realistic-style` | Fotorealizm AAA, fotogrametria, PBR. |
| `stylized-style` | Stylizacja ogólna: język kształtów, NPR. |
| `lowpoly-style` | Low-poly PS1/PS2, czytelne sylwetki. |
| `psx-horror-style` | PSX + horror: affine tekstury, mgła. |
| `anime-style` | Anime/cel-shading, toon shadery. |
| `manga-style` | Manga: monochrom, screentone, speed lines. |
| `cartoon-style` | Kreskówka: squash-stretch, mocne kolory. |
| `chibi-style` | Chibi/SD: duże głowy, uproszczona anatomia. |
| `comic-book-style` | Komiks: tusz, halftone, kontrast. |
| `hand-painted-style` | Ręcznie malowane tekstury. |
| `painterly-style` | Akwarela / olej. |
| `pixel-art-style` | Pixel art i ograniczony texel. |
| `retro-8bit-style` | Estetyka NES. |
| `retro-16bit-style` | Estetyka SNES/Genesis. |
| `hd-2d-style` | Sprite'y pikselowe w scenie 3D z DOF. |
| `voxel-style` | Woksele / bloki. |
| `isometric-style` | Izometria, diorama, kafle. |
| `vector-style` | Płaskie wypełnienia, ostre sylwetki. |
| `minimalist-style` | Minimalizm, negatywna przestrzeń. |
| `noir-style` | Noir: kontrast, mokre ulice. |
| `frutiger-aero-style` | Frutiger Aero: glossy, aqua, lata 2000. |
| `stop-motion-craft-style` | Plastelina, papier, rękodzieło. |
| `visual-console-eras` | Epoki konsol PS1–PS5, arcade, DOS, CRT, VHS. |
