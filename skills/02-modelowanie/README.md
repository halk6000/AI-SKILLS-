# Modelowanie 3D

**Kiedy:** Tworzenie geometrii — wybierz wg typu obiektu.

> **Najpierw własny skill [modelowanie](../../modelowanie/SKILL.md):** doświadczenie zbieramy najpierw z anatomii (które punkty zmienić, jak ocenić) w OBJSmith z folderu `Edytor`. Wyniki → [anatomi.md](../../modelowanie/dos/anatomi.md).

| Skill | Do czego |
|---|---|
| `hard-surface` | Sci-fi, broń, pojazdy, mechanika: boolean/bevel, panele, greeble. |
| `prop-artist` | Przyziemne propsy: meble, narzędzia, przedmioty codzienne. |
| `vehicle-artist` | Samochody, statki, samoloty, mechy z LOD. |
| `character-artist` | Postacie: anatomia, topologia twarzy, ubrania, mesh pod animację. |
| `creature-artist` | Stwory, potwory, obcy — wiarygodna anatomia. |
| `environment-artist` | Środowiska: modularne kity, budynki, teren, kompozycja. |
| `vegetation-artist` | Drzewa, rośliny, trawa z kart, atlasy liści. |
| `sculpting` | Rzeźba: Dyntopo, multires, alphy, zmarszczki, uszkodzenia. |
| `retopology` | Retopo pod animację: quady, edge loopy. |
| `procedural-modeling` | Proceduralne skały, budynki, drogi, rury, kable. |
| `geometry-nodes` | Geometry Nodes: scatter, instancje, reużywalne node groupy. |
| `hair-groom` | Włosy i futro: curves, particle hair, karty włosów. |
| `collision-proxy` | Kolizje do gier: UCX/UHX, convex hull, kapsuły. |
