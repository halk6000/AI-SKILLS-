# Eksport i silniki gier

**Kiedy:** Ostatni krok przed silnikiem/webem.

| Skill | Do czego |
|---|---|
| `export-pipeline` | Ogólny eksport FBX/GLTF/OBJ/USD/Alembic ze sprawdzeniem skali i osi. |
| `unity-export` | Specyfika Unity: skala, rigi humanoid, LOD, kolizje. |
| `unreal-export` | Specyfika Unreal: FBX, UCX, sockety, skeletal mesh. |
| `godot-export` | Specyfika Godot: GLTF/GLB, klipy animacji, kolizje. |
| `threejs-export` | GLB + gotowa przeglądarka Three.js w HTML. |
| `lod-pipeline` | Generowanie i walidacja LOD-ów. |
