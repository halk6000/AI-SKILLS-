# Programowanie i Claude Code

**Kiedy:** Kod, review, automatyzacje, rozszerzanie samego AI.

| Skill | Do czego |
|---|---|
| `code-review` | Review diffu/PR pod kątem błędów. |
| `simplify` | Upraszczanie i porządki w kodzie. |
| `security-review` | Przegląd bezpieczeństwa. |
| `run` | Uruchomienie aplikacji i sprawdzenie zmiany na żywo. |
| `init` | Inicjalizacja CLAUDE.md w projekcie. |
| `claude-api` | API Claude / Anthropic SDK. |
| `anthropic-skills:skill-creator` | Tworzenie nowych skilli — gdy w bazie brakuje. |
| `plugin-authoring` | Mody: motywy, panele, hooki, slash-komendy. |
| `cowork-plugin-management:create-cowork-plugin` | Tworzenie pluginu. |
| `cowork-plugin-management:cowork-plugin-customizer` | Dostosowanie pluginu. |
| `workflow-authoring` | Skrypty workflow wielu agentów. |
| `update-config` | settings.json, hooki, uprawnienia. |
| `fewer-permission-prompts` | Allowlista komend — mniej pytań o zgodę. |
| `keybindings-help` | Skróty klawiszowe. |
| `loop` | Powtarzanie zadania w interwale. |
| `schedule` | Zaplanowane agenty w chmurze (cron). |
| `artifact-capabilities` | Strony z danymi na żywo, stanem, plikami. |
| `anthropic-skills:setup-claude` | Konfiguracja Claude. |
| `anthropic-skills:explain-usage` | Wyjaśnienie zużycia/limitów. |
