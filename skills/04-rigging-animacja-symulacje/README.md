# Rigging, animacja, symulacje, 2D

**Kiedy:** Ruch, deformacje, fizyka i animacja 2D.

| Skill | Do czego |
|---|---|
| `rigging` | Armatury, IK/FK, wagi, rigi mechaniczne i twarzy, drivery. |
| `animation` | Cykle chodu/biegu/idle, walka, Graph Editor, NLA. |
| `blender-motion-capture` | Import BVH/FBX mocapu, retarget, tracking kamery. |
| `cloth-sim` | Symulacja ubrań, pin groupy, bake do shape keys. |
| `physics-sim` | Rigid/soft body, destrukcja, cell fracture. |
| `vfx-fx` | Dym, ogień, cząsteczki, smugi. |
| `blender-grease-pencil` | Rysunek i animacja 2D Grease Pencil z kodu — przydatne do klatek/sprite'ów. |
