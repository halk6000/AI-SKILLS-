# Blender — rdzeń i pipeline

**Kiedy:** Zawsze najpierw przy pracy w Blenderze: obsługa MCP, planowanie, kontrola jakości.

| Skill | Do czego |
|---|---|
| `blender-mcp` | Instrukcja obsługi Blendera przez MCP: health check, batchowany bpy, różnice API 4.x/5.x, screenshoty, timeouty. ŁADUJ PIERWSZY. |
| `blender-director` | Planowanie pipeline'u assetu i koordynacja innych skilli; dopasowanie do referencji. |
| `blender-modeler` | Ogólne modelowanie: Edit Mode, modyfikatory, blockout, porządek w scenie. |
| `blender-addon-dev` | Pisanie własnych add-onów: operatory, panele UI, właściwości, pakowanie. |
| `scene-assembly` | Duże sceny: kolekcje, linkowanie, override'y, organizacja pod streaming. |
| `asset-optimization` | Walidacja przed eksportem: polycount, topologia, UV, materiały, nazewnictwo. |
| `qa-review` | Bramka jakości: screenshoty, checklisty, werdykt ship/no-ship. |
