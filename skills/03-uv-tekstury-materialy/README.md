# UV, tekstury, materiały

**Kiedy:** Po modelowaniu, przed eksportem.

| Skill | Do czego |
|---|---|
| `uv-workflow` | Rozwijanie UV: szwy, packing, texel density, UDIM, lightmapy. |
| `texture-workflow` | Atlasy, bake AO/curvature/normal, decale, pamięć tekstur. |
| `materials` | Materiały PBR i stylizowane: metal, drewno, beton, rdza, szkło. |
| `lookdev` | Pętla materiał + światło + kamera aż shading wygląda dobrze. |
| `polyhaven-texture-apply` | Nałożenie tekstury PBR z PolyHaven na obiekt. |
| `polyhaven-material-swap` | Warianty materiałów/kolorów z renderem każdego. |
