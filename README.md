# AI-SKILLS-

Wspólna biblioteka skilli i doświadczeń AI. Cel: lepiej rozumieć intencje użytkownika, trafiać w właściwy skill i nie powtarzać błędów.

## Start
- [PROMPT.md](PROMPT.md) — prompt „najpierw skill, jak brak — dedukuj”
- [INDEX.md](INDEX.md) — katalog 168 gotowych skilli w 16 kategoriach + luki

## Własne skille (zasady + doświadczenia `dos/`)
- [sposob-pracy](sposob-pracy/SKILL.md) — współpraca, decyzje i zatwierdzanie
- [modelowanie](modelowanie/SKILL.md) — geometria i modele 3D; **najpierw anatomia w OBJSmith** ([dos/anatomi.md](modelowanie/dos/anatomi.md))
- [generowanie-obrazow](generowanie-obrazow/SKILL.md) — referencje, grafika i animacje
- [nomenklatura](nomenklatura/SKILL.md) — nazwy i pojęcia
- [programowanie](programowanie/SKILL.md) — projekty i Git
- [testowanie](testowanie/SKILL.md) — sandbox i testy
- [komunikacja](komunikacja/SKILL.md) — odpowiedzi i raporty
- [_szablony](_szablony/SKILL.template.md) — wzorzec nowego skilla

Kolejność: **własny skill → kategoria z INDEX.md → dedukcja.** Własne zasady i doświadczenia mają pierwszeństwo przed ogólnymi skillami z katalogu.

## Rozwijanie biblioteki

Gdy użytkownik podaje kluczową, powtarzalną wskazówkę, sprawdź istniejące instrukcje. Uzupełnij odpowiedni skill albo utwórz nowy, jeśli rzeczywiście jest potrzebny. Nie utrwalaj jednorazowych poleceń ani żartów. Rozróżniaj potwierdzone zasady i propozycje. Zmiany przedstaw do ręcznego zatwierdzenia przez pull request. Nie zapisuj prywatnych danych, sekretów ani treści rozmów. Aktualne polecenia i zasady bezpieczeństwa mają pierwszeństwo.

Każdy dział może zawierać kolejne niezależne skille w podfolderach. Biblioteka jest niezależna od modelu; adaptery dodawaj w razie potrzeby.
