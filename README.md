# AI-Skills

Wspólna biblioteka doświadczeń AI. Cel: lepiej rozumieć intencje użytkownika i nie powtarzać błędów.

## Działy

- sposob-pracy — współpraca, decyzje i zatwierdzanie
- modelowanie — geometria i modele 3D
- generowanie-obrazow — referencje, grafika i animacje
- nomenklatura — nazwy i pojęcia
- programowanie — projekty i Git
- testowanie — sandbox i testy
- komunikacja — odpowiedzi i raporty
- _szablony — wzorzec instrukcji

## Rozwijanie biblioteki

Gdy użytkownik podaje kluczową, powtarzalną wskazówkę, sprawdź istniejące instrukcje. Uzupełnij odpowiedni skill albo utwórz nowy, jeśli rzeczywiście jest potrzebny. Nie utrwalaj jednorazowych poleceń ani żartów. Rozróżniaj potwierdzone zasady i propozycje. Zmiany przedstaw do ręcznego zatwierdzenia przez pull request. Nie zapisuj prywatnych danych, sekretów ani treści rozmów. Aktualne polecenia i zasady bezpieczeństwa mają pierwszeństwo.

Każdy dział może zawierać kolejne niezależne skille w podfolderach. Biblioteka jest niezależna od modelu; adaptery dodawaj w razie potrzeby.
